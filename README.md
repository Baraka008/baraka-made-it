# Baraka Portfolio

This portfolio showcases the work of Baraka, a growing web developer focused on building clean, responsive, and user-friendly project experiences.

## Featured project

The main project highlighted in this portfolio is Liuwa Gardens, a hospitality-focused website created to represent a hotel and garden experience. It includes:

- A warm, welcoming landing page
- Information about rooms and services
- Food and menu presentation
- A cart and ordering interaction for food items
- Responsive layout styling for desktop and mobile
- JavaScript-powered behavior using local storage for data persistence

## Why this portfolio matters

This project demonstrates a combination of:

- Front-end design thinking
- Responsive layout implementation
- Real interactivity with JavaScript
- User-centered design choices
- A strong visual identity for a business website

## Tech used

- HTML
- CSS
- JavaScript
- Local storage for cart and menu data

## Purpose of the page

The portfolio is designed to present Baraka as a creative and practical developer, with a strong emphasis on polished front-end work and a clear, modern personal brand.
