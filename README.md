# Baraka Portfolio

This portfolio presents the full range of Baraka's public repositories, including the projects that highlight web design, front-end development, interactive interfaces, and digital product experimentation.

## Featured portfolio projects

### Liuwa Gardens
Repository: https://github.com/Baraka008/baraka-made-it

This is a hospitality website concept built around a hotel and garden experience. It includes a welcoming homepage, services, rooms, food/menu cards, and an interactive cart system. The project demonstrates front-end design thinking, custom styling, and JavaScript-driven functionality using local storage.

### AuroraMusic
Repository: https://github.com/Baraka008/AuroraMusic
